# Contributing to Modern AI System Design Patterns

First off, thank you for considering contributing to this repository! The goal is to build the definitive open-source library for AI architecture.

## How to Submit a New Pattern

1. **Fork the repository.**
2. **Create a new file** in the `/patterns` directory.
3. **Use the Standard Template:** Every pattern must include:
   - A `mermaid.js` sequence or flowchart diagram.
   - **Cost Analysis:** Estimated infrastructure costs at scale.
   - **Latency Bottlenecks:** Where the system slows down and how to fix it.
   - **Security Guardrails:** Vulnerability mitigation.
4. **Update the README:** Add a link to your new pattern in the table on the main `README.md`.
5. **Submit a Pull Request.**
